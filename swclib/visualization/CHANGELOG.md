# SWC Studio 版本记录

本文件只记录 `swclib.visualization` 的变化，独立于 swclib 核心库版本。每次可视化功能修复或优化后必须追加/更新对应版本条目，同时更新 `__init__.py` 中的版本号。

## 0.8.0 — 2026-10-15

- 划分脑区新增“微调平面并平衡两侧”，默认 10°、可调 0–90°。候选平面均经过当前可见数据包围盒中心；先缩小完全左／右数量差，差小于 5 后优先减少跨侧数，再比较数量差及转角。
- 最多提供 3 个方向有区别的建议，默认应用第一项，可切换预览并导出当前选择。采用有限局部搜索，不保证全局最优；统计完整可见 SWC，沿用导出的线段长度分类，不要求唯一胞体。手动改参、可见集合／中心变化时丢弃旧结果。
- 普通 SWC 加载顺带准备几何摘要，后续搜索复用最多 64 MiB 缓存；凸包摘要逐点验证保守投影误差界，退化几何使用分块包围盒，不确定时读取完整几何精确判断。源文件变化时失效，避免每个候选重读全体神经元或合并所有节点。
- 兼容当前 SciPy 构建的 Qhull 诊断流，使用匿名内存描述符，无需允许只读工作进程创建临时文件或放宽源文件保护。
- 验证：88 项 Python 测试通过；Chromium 验证候选切换、精确参数同步、角度／中心约束、完整 SWC 计数与选中平面导出、迟到响应丢弃、窄屏及原有脑区插件回归，源文件内容、mtime 和权限不变。
- 大数据实测：Xeon Platinum 8358P 2.60 GHz（128 个可用逻辑 CPU），I3 的 1004 个神经元、49,604,050 个节点，4 进程、410 个候选，复用摘要搜索 4.78 秒。无摘要缓存首次总计 94.69 秒，其中摘要准备 90.31 秒；普通 SWC 加载会提前准备摘要。计时不包含进程启动、浏览器渲染和独立分类复核。
- 全量独立复核：最佳平面的 1004 个神经元分类与原有逐线段导出计算完全一致；该次摘要缓存约 8.04 MiB。默认 X 法向的居中基准为左 263／右 256／跨侧 485，第一建议为左 263／右 266／跨侧 475（转角约 7.82°）。

## 0.7.0 — 2026-10-15

- 三维相机改为轨迹球与归一化四元数，可自由组合观察方向和绕视线的滚转；边缘绕圈拖动或 Alt + 左键水平拖动支持滚转，保留平移、缩放、XYZ 方向轴、正交切片和目标定位。
- 划分脑区增加数量统计按钮：基于当前可见神经元的完整 SWC，沿用导出的两侧线段长度分类，显示完全左侧、完全右侧、跨侧、总数及左右含跨侧合计。统计无需唯一胞体；平面或可见集合变化时使结果失效，丢弃旧请求的迟到结果。
- 导出支持已有目录或指定 JSON 文件路径；目标存在时提示取消/确认覆盖。默认请求保持不覆盖，确认后原子替换，序列化或统计失败保留旧文件，链接替换不会改写链接目标。
- 验证：53 项 Python 测试、4 项相机数学检查通过；Chromium 验证数量、裁剪后的完整 SWC、旧结果失效、自定义路径和覆盖取消/确认、胞体歧义及窄屏布局，测试源文件内容/mtime/权限保持不变。
- 浏览器回归通过真实轨迹球拖动、Alt 滚转、连续旋转后的正交基、XYZ 方向轴、三维/切片目标定位、1 万/10 万节点与 300³ 图像叠加、并行读取及裁剪/移除竞态。常规 SWC 仍为两次绘制，源文件保持不变。

- 法向正侧为右、负侧为左，与参考 `brain_hemisphere.json` 一致。交互只更新平面参数，启用时额外 1 次绘制，不重读源文件、不重新上传 SWC 几何，原有两种着色模式保留。

- 增加明确的新 JSON 导出通道：请求/读取线程仍受内核只读保护，专用写入线程只在指定服务端已有目录原子发布新的 `brain_hemisphere.json`，不覆盖已有文件或链接，不修改输入数据。
- 并行统计共享 SWC 解析和内存限额，错误时释放全部占用；关闭进程池时主动释放引用，避免同步资源延迟到受保护请求线程中清理。
- 验证：47 项 Python 测试通过；修改关闭流程后，相关 23 项复验通过且无同步资源清理告警。Chromium 验证平面、左右标签、参数同步、拖动零读取、裁剪坐标、可见条目完整导出、覆盖保护、胞体歧义拒绝及窄屏布局；源文件内容/mtime/权限不变。
- 平面完全侧对视线时以抗锯齿分隔线显示，仍为同一次绘制。查看胞体插件和原有 1 万/10 万节点、300³ 图像、目标定位、并行裁剪/移除回归通过。
- 与给定示例的 32 个神经元及对应 `single-neurons-step2` 原始文件核对，左右/cross 分类和胞体侧别全部一致；左右及总长度最大差异 4.9×10⁻⁹，胞体坐标/有符号距离最大差异 1.9×10⁻¹²，仅为浮点计算差异。
- 安装验证：最终 wheel 隔离安装后，在源码目录外运行命令报告 0.6.0，平面插件资源与 JSON 导出可用，4 路 SWC 读取正常；SIGINT/SIGTERM 均正常退出并清理读取子进程。

## 0.5.0 — 2026-10-14

- 右侧新增与 SWC、图像并列的“插件”标签页，以及可折叠的内置插件列表，首个插件为“查看胞体”。
- 输入全脑目录/模式、crop 立方体边长及 SWC 文件/目录后，自动并行扫描胞体候选；每文件优先全部 type=1 节点，无此标记时使用 parent=-1 根节点并明确标记候选。多个候选分别列出，支持筛选与每页 50 项，坏文件/无候选不阻断其余扫描。
- 点击候选后按全脑全局体素坐标读取图像和对应 SWC crop，以局部坐标叠加并居中；边界附近向内平移以保留立方体边长，超界候选不可选，继续遵守 300³ 和内存限制。
- 扫描阶段只读取 SWC/全脑元数据，不解码图像、不上传全部几何；候选识别复用现有 Swc 解析器和受只读保护的 SWC 进程池，共享并发/内存限额。候选小块沿用独立区域列表和按需加载。
- 图像/标注准备完成后一起切换，失败时保留原场景；快速选择、取消扫描、修改参数、手动切换数据时丢弃过期结果，源文件始终只读。
- 验证：33 项 Python 测试通过；Chromium 检查 66 个候选的分页/筛选、2 路并行、扫描期间零像素请求、边界裁剪与叠加、快速切换、读取失败保留场景及手动取消；桌面/窄屏布局通过，源文件内容/mtime/权限不变。
- 补充验证：取消扫描、递归目录、单文件、TIFF/FNT 输入均通过；原有 1 万/10 万节点、300³ 图像、crop、右键定位和并行迟到响应回归通过，常规 SWC 仍为 2 次绘制调用。wheel 隔离安装后，命令版本、新插件资源与胞体候选接口可用，SIGINT/SIGTERM 正常退出。

## 0.3.0 — 2026-10-13

- 三维相机解除垂直 ±89° 限制，水平/垂直均可连续旋转 360°；周期归一化角度，越过极点时仍保持有效的正交视图基底。
- 左下角新增随相机变化的 XYZ 方向轴，X 红、Y 绿、Z 蓝，区分正负方向；在三维、正交和窄屏视口中显示。仅更新独立小画布，不增加 SWC 绘制调用。
- SWC 使用受限前端并发队列和服务端进程池；默认自动选择最多 4 进程，可通过 `--swc-workers 1..8` 调整。进程预热并复用现有 `Swc`，绕过 Python GIL 的解析串行限制。
- 子进程启动即安装只读保护；并发限制覆盖解析到 HTTP 传输，增加按文件大小的内存预算，多个标签页共享限额。图像仍为独立串行读取、单幅显示。
- 二进制进程间传输、批量 Worker 组装及 GPU 上传；每节点颜色用 uint32 直接复制，减少临时数组分配，保留完整几何和两次 SWC 绘制调用。
- 并行加载时保留隐藏、移除、crop 的过期请求检查，单文件读取失败不影响其余文件；右侧显示并发数和处理进度。
- 加载对照：32 个 SWC、共 32 万节点，预热文件缓存，三轮 HTTP 耗时中位数单进程 2.323 秒 / 4 进程 0.810 秒（2.87 倍）；二进制结果一致。测试不含浏览器/GPU及启动耗时，机器允许 128 个 CPU 核心，实际加速依硬件和文件规模而变。
- 验证：26 项 Python 测试通过；Chromium 检查实际拖拽越过极点、完整旋转、方向轴同步、4 路并发、加载中移除/crop、坏文件及迟到响应，通过 300³ 图像和原有交互回归，测试源文件内容/mtime/权限不变。
- 浏览器回归：Chromium 148 / SwiftShader / 1280×900，1 万节点加载约 0.37 秒、约 37 FPS；10 万节点加载约 0.51 秒、约 8 FPS，SWC 均为 2 次绘制。加载优化不等同于 GPU 帧率提升，软件渲染仍受设备及负载限制。
- 安装验证：wheel 构建/隔离安装通过，源码目录外运行 `swclib-viewer`，静态资源和 4 路 SWC 请求可用；Ctrl+C 和 SIGTERM 均正常退出并清理读取子进程。

## 0.2.0 — 2026-10-13

- 图像和全脑 crop 的 X/Y/Z 每轴硬上限设为 300，最多 300³；默认显示体预算从 64 MiB 调至 128 MiB，前后端同时调整，保留可用内存/解码开销检查。更大的命令行或客户端容量参数也不能绕过 300 上限。
- 新增“视野中心”XYZ 输入、定位和当前中心回填，保持缩放与旋转；使用 crop 后的显示坐标，正交视图同步对应切片。
- SWC、图像及全脑条目支持单项/批量移除。批量选择与显示开关独立；仅移除内存登记及 GPU/Worker 缓存，保留源文件；被移除条目的迟到读取结果会丢弃。
- 保持神经元颜色槽位稳定，支持移除后的稀疏调色板和重新添加，不重读剩余 SWC。
- 新增 Linux/libseccomp 请求线程文件只读保护，拦截写入打开、截断、删除、重命名和文件元数据修改；保护失败时拒绝数据请求。系统需提供 `libseccomp.so.2`。
- HTTP 接口启用请求字段白名单，列表移除接口只接受条目 ID，没有磁盘删除或保存接口。
- 验证：22 项 Python 测试通过（19 项数据/只读规则测试，3 项 HTTP 测试）；Chromium 实际加载 300³ float32 图像、中心定位、SWC/图像单项及批量移除通过；所有测试源文件 SHA-256、mtime、权限不变，无图像 sidecar 写入。
- 安装验证：wheel 构建和隔离安装通过，已安装命令报告 0.2.0，静态资源及带只读保护的 SWC 接口在源码目录之外可用。
- 回归基准：Chromium 148 / SwiftShader / 1280×900，1 万节点约 41 FPS，10 万约 9 FPS，SWC 均为 2 次绘制调用。软件渲染结果随机器负载波动，完整拓扑和渲染分辨率保持不变。

## 0.1.0 — 2026-10-13

首次实现可随 swclib 安装的本地可视化网站。

### 功能

- 新增 `swclib-viewer` 命令，支持指定 host/port、自动打开浏览器、预登记 SWC/图像路径和显示容量上限。
- WebGL2 点线 SWC，文件/目录批量加载、逐神经元显示开关、点大小、点/线开关与不透明度。
- 两种颜色模式：拓扑着色（蓝根、红色度数 2、绿色分叉、黄色叶子）；每个神经元一种稳定颜色。
- XYZ 半开区域裁剪，显示坐标减去 start，复用 `Swc.read_region`。
- 小块灰度 TIFF/NRRD/NPY；图像单选、按需读取和切换释放纹理。
- FNT 和 TIFF 切片全脑区域读取，复用 `WholeBrainReader`；元数据/内存/解码工作区/GPU 纹理限制联合检查，超限读取前拒绝。
- SWC 和图像同坐标空间叠加；MIP、体渲染和三向切片；亮度、黑白场、Gamma、自动对比度与透明度。
- 使用浮点图像纹理，保留弱信号的可调性，不预量化为 uint8。

### 性能与边界修复

- 多神经元共享 GPU 批次；完整节点及边，无拓扑抽样；点和线共两次绘制调用。
- 二进制传输、可转移缓冲区、Web Worker 几何组装、GPU 调色板可见性及颜色切换。
- 按需重绘，设备像素密度与抗锯齿保持不变。
- 登记去重使用索引，避免大量文件扫描时逐项比较已有列表。
- 处理空 SWC/空 crop；切换/裁剪后过期请求不会覆盖当前场景；服务端限制并发解码。
- 单色图像正常显示，归一化工作区按行受限；图像内存预算包括完整 FNT cube/切片及 GDAL 缓存。

### 验证

- Python 行为测试：拓扑及颜色、裁剪和边界、惰性读取、浮点灰度、超限拒绝、TIFF/NRRD/NPY 和 FNT 相交块读取。
- 真实 Chromium 浏览器验收：两种颜色、显示开关、图像单选、全部渲染模式、SWC/图像叠加、crop 和全脑区域检查。
- wheel 构建及隔离安装验收通过：从源码目录之外运行已安装的 `swclib-viewer`，验证命令、全部静态资源、Web Worker 和 SWC 接口。
- 首次软件渲染基准（Chromium 148 / SwiftShader / 1280×900）：1 万节点约 60 FPS；10 万节点约 14 FPS；均为 2 次 SWC 绘制调用。后者包括额外隐藏的 1 万节点缓冲。详情和复现方法见 README。

### 当前限制

- 浏览器需要 WebGL2；帧率受 GPU、设备像素密度和数据分布影响，软件渲染 10 万节点仍有性能边界。
- 图像为单通道二维/三维标量体；不自动换算物理 spacing 或 affine；SWC 和图像需使用相同体素坐标系。
- 以保守容量估计限制图像 ROI，不承诺任意硬件上的固定帧率；原始数据不修改、不降采样。
- 工作空间状态位于当前服务/标签页内；不提供标注编辑或多用户认证。
